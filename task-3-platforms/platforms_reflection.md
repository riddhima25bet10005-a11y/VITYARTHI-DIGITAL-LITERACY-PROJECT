## Part B – Google Workspace: Digital Literacy Awareness Quiz

I built a **5-question Digital Literacy Awareness Quiz** using Google Forms. The form is designed to be shared with batchmates as part of the Student Digital Ambassador initiative. It includes:

| # | Question | Type |
|---|----------|------|
| 1 | What is Digital Literacy? | Multiple Choice |
| 2 | Which of these is a safe password practice? | Multiple Choice |
| 3 | Name one platform used for professional networking. | Short Answer |
| 4 | What should you do if you receive an unknown OTP? | Multiple Choice |
| 5 | What is the National Cyber Crime helpline number? | Short Answer |

The form is connected to a Google Sheet that collects and organises all responses automatically. I enabled the "Collect email addresses" option so responses can be tracked by participant.

## Reflection
HackerEarth surprised me with how beginner-friendly it is compared to other platforms I had heard about. The interface clearly shows which test cases pass and which fail, which helped me understand that programming is not just about writing code — it is about writing code that handles all possible inputs correctly. The Google Forms exercise was valuable in a different way: designing good quiz questions is harder than it looks. I had to make sure each multiple-choice question had plausible wrong answers, not obviously incorrect ones, so the quiz actually tests knowledge rather than guesswork. Both platforms will be useful throughout my degree — HackerEarth for technical practice, and Google Forms for collecting data in project surveys and lab feedback.
